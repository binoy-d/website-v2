THIS IS FROM DANIEL, TO DANIEL:


where stuff lives:

   projects / experience / skills / about text / taglines  ->  server/content/*.json
   project screenshots + profile photo                      ->  server/content/images/
   (the React app fetches all of it from /api/content; no need to touch src/ for content edits.
    put the screenshot in images/, reference it by file name in the json, done.)

steps to push an update:

1. do the code changes, commit, and push to master (from any computer)
2. that's it. GitHub Actions runs the tests + build, then the self-hosted
   runner on binoyserver pulls master and rebuilds the docker containers.
   watch it at https://github.com/binoy-d/website-v2/actions
   (re-run by hand: "gh workflow run deploy", or the Run workflow button)
3. give it ~5 minutes, check https://binoy.co

manual fallbacks:
   from a machine with ssh access:  make deploy
   on the server itself:            cd ~/dev/website-v2 && git pull && ./scripts/server-deploy.sh
   logs:                            cd ~/dev/website-v2 && docker compose logs -f --tail=100

secrets (BookOrbit login for the Highlights page) live in ~/dev/website-v2/.env
ON THE SERVER, not in git. the runner lives in ~/actions-runner-website.

if not working, figure it out lmao
