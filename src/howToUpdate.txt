steps to push an update:

1. do the code changes and commit to master
2. cd to repo directory, and "make deploy"
   (needs .env.deploy with DEPLOY_HOST — see .env.deploy.example)
3. it rsyncs the repo to the server, rebuilds the docker images there,
   restarts the containers, and checks /api/health
4. give it a minute, check if it works
5. logs:    ssh <server> 'cd dev/website-v2 && docker compose logs -f --tail=100'
   status:  ssh <server> 'cd dev/website-v2 && docker compose ps'
6. secrets (ADMIN_TOKEN, SMTP) live in .env ON THE SERVER, not in git
7. if not working, figure it out lmao
